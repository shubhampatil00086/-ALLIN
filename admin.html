Security checklist

  • Admin role is a Firebase ID-token custom claim: admin: true.
  • Never grant admin based on an email comparison or user-editable field.
  • Use Firestore and Storage Rules; frontend guards are not security boundaries.
  • Use Cloud Functions for approvals, booking transitions, WhatsApp, payments, audit logs and complete exports.
  • Never publish service-account JSON or private provider credentials.
  • Test rules before launching with real users.
